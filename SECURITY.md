# Security

Agent Wallet Firewall is early software (version 0, testnet only). Do not use it with a wallet that holds real money yet.

## Reporting a vulnerability

If you find a way to get a transaction past the firewall that it should have stopped, please do not open a public issue. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability").

Bypasses are the most valuable reports. With your permission, confirmed ones become new scenarios in the Agent-Drain-Benchmark, credited to you.
